◈ Lit web component

Drag anything, declaratively.

<movable-el> is a tiny wrapper that makes any element draggable — no framework, no drag-and-drop boilerplate. Constrain axes, snap to a grid, clamp to bounds, or drag a whole dialog by its title bar. Every demo below is live — grab a box and the code that built it.

★ GitHub npm package npm i lit-movable

Basics

Free movement

Drop any content inside <movable-el> and it becomes draggable. Zero configuration.

live demo
✥
 
<movable-el posTop="90" posLeft="120">
  <div>✥</div>
</movable-el>
Axis lock

Horizontal only

axis="x" locks the vertical position. boundsX="-50,250" clamps travel, relative to the start point.

live demo
⇄
 
<movable-el axis="x" boundsX="-150,150">
  <div></div>
</movable-el>
Axis lock

Vertical only

The same trick with axis="y" — handy for vertical sliders and splitter controls.

live demo
⇅

Snapping

50px grid + Shift

grid="50" snaps each step. Hold Shift while dragging to constrain to the dominant axis.

live demo · watch the 25px gridlines
snap!
 
<movable-el grid="50" shiftBehavior>
  <div>snap! 50px grid</div>
</movable-el>
Handles & targets

Drag a dialog by its title

The handle slot is the only grabbable part, and targetSelector moves an outer element — the classic modal pattern.

live demo
drag this title bar
This body text is not a handle — only the title bar starts a drag.
<div id="dialog">
  <movable-el targetSelector="#dialog">
    <div slot="handle">Title</div>
  </movable-el>
  Body is not a handle.
</div>
Bounds

Clamped to a box

Bounds are deltas from the current position: at (100,100), "-100,100" means absolute [0,200]. The knob can't escape the green arena.

live demo 
<!-- relative bounds: pos ± 100 → [0, 200] -->
<div style="position:relative">
  <movable-el posTop="100" posLeft="100"
    boundsX="-100,100" boundsY="-100,100">
    <div class="knob"></div>
  </movable-el>
</div>

  console.log(detail.coords, detail.totalDist);
});

el.onmoveend = (state) =>
  console.log(state.posLeft, state.posTop);

Disabled toggle

Flip the disabled attribute to freeze a movable in place — useful while a form is submitting or a layout is locked.

live demo
I'm frozen — enable me below
 
<movable-el disabled>
  <div>I can't be dragged</div>
</movable-el>

// toggle from JS
el.disabled = false;

Attribute reference

Everything is an attribute (and reflected property) — no JS required for the common cases.

AttributeTypeDescription
posTop / posLeftNumberInitial / reflected top / left in px. Set these before bounds when both change in one update.
targetSelectorStringCSS selector for the element that moves (default: the <movable-el> itself).
boundsX / boundsYStringRelative "min,max" offsets from the current position — not document coords. "null" locks that axis.
axis"x" | "y"Lock the other axis to its current position.
gridNumberSnap increment in px (default 1).
dragAfterDistNumberPointer travel in px before a drag starts (default 0) — lets clicks pass through.
shiftBehaviorBooleanWith open bounds, holding Shift constrains movement to the dominant axis.
disabledBooleanDisable dragging entirely.
eventsOnlyBooleanFire events without repositioning the target — drive your own transforms.
